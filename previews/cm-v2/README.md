# CM v2 / 01 美術樣本

狀態：完成可互動樣本，待 Cayden 確認；不是全套素材或正式產品功能。

直接用瀏覽器開啟 `index.html` 即可，所有資源均在本目錄，沒有網路依賴、API、儲存或正式資料寫入。手機可複製整個目錄後以瀏覽器開啟，或由同網路的開發機提供靜態 HTTP 預覽。未納入 Vite 正式建置，不新增公開產品入口。

## 樣本與交付規格

- 代表種類：既有貓、新增牛；兩個靜態學生頭像及各三階段吉祥物。延伸既有 AnimalAvatar.tsx 的原創向量語言，無外部圖庫或生成式點陣素材。
- SVG viewBox：`0 0 120 140`；角色耳／角頂約 y=21、腳底 y=130。階段保持同一可見高度與腳底，調整頭身比例、領巾及成熟吊飾；不把留白當成成長。
- 農場基準畫布為 140×140 CSS px（SVG 等比置中），腳底 anchor 固定；倍率 `1 + .03 * min(max(level-1,0),20)`。Lv.1／5／10／21 為 1／1.12／1.27／1.60；Lv.22 尺寸不再增加。對照卡為 100×100 基準，四張使用同一尺度。
- 原色：深綠描邊 #405849、貓 #edc889、牛 #fff5df、棕斑 #ac8261，2.8 單位圓角描邊。學生角色維持靜態。
- 動畫交付：SVG 分組＋CSS keyframes；外層位移、尺寸倍率、內層動作分開。待機呼吸、走動上下小步及交替擺腿、成功餵食咀嚼／點心／愛心約兩秒後回待機。失敗不播放成功動作。
- 走動為正面角色左右小步往返，刻意不翻轉整張圖；若本人希望側身行走，在樣本確認時提出後再調整。
- 初次載入尊重系統 reduced-motion，勾選靜態模式可停動畫；明確點擊待機／走動／餵食成功可主動開啟，手動選擇優先於系統預設；隱藏頁面暫停動畫且取消未完成餵食演出。狀態文字仍能表達操作結果。無動畫定時後端請求。
- 當前檔案：`index.html` 結構、`preview.css` 場景／動作、`preview.js` 向量構圖／本機控制。
- 後續正式整合建議：學生 SVG 放 `frontend/src/art/students/`，吉祥物按種類／階段放 `frontend/src/art/mascots/`，共用動作與場景放該目錄共用模組。正式頁只載入當前階段；本預覽刻意展示全部代表階段。須等樣本確認，不先產生全套。
